
## IA Generativa

A IA generativa evoluiu para uma ferramenta central no desenvolvimento de software, auxiliando programadores na criação de código, automação e produtividade.

Ela consegue:

- gerar código
- corrigir erros
- explicar algoritmos
- documentar aplicações
- criar testes
- sugerir melhorias arquiteturais

### Exemplo

Um desenvolvedor pode pedir:

> “Crie um sistema de autenticação usando Spring Boot e JWT”

A IA gera:

- controllers
- services
- repositories
- configuração de segurança
- tokens JWT

Além disso, consegue analisar a arquitetura do projeto e adaptar o código ao padrão já utilizado.

---

# LLMs (Large Language Models)

LLMs são modelos de IA treinados com enormes quantidades de texto para compreender e gerar linguagem natural.

### Exemplos:

- OpenAI ChatGPT
- Google Gemini
- DeepSeek DeepSeek
- Anthropic Claude

---

# Capacidades dos LLMs

Os LLMs modernos conseguem:

- compreender linguagem natural
- gerar código
- resumir textos
- responder perguntas
- traduzir idiomas
- executar tarefas autônomas
- pesquisar na web
- usar ferramentas externas
- agir como agentes inteligentes

---

# Limitações dos LLMs

## Alucinações

Podem gerar:

- código incorreto
- informações falsas
- respostas inventadas

Por isso:

- sempre valide o código
- teste respostas
- revise segurança e lógica

---

## Alto custo computacional

Modelos grandes exigem:

- GPUs poderosas
- muita memória
- grande consumo energético

---

## Limitações de contexto

Modelos possuem limite de tokens e podem:

- esquecer partes antigas da conversa
- perder contexto em projetos muito grandes

# NLP (Processamento de Linguagem Natural)

NLP é a área da IA que permite que computadores entendam e gerem linguagem humana.

### Usos:

- chatbots
- tradutores
- assistentes virtuais
- análise de sentimentos
- busca inteligente
- geração de texto

---

# Arquitetura Moderna de NLP

## Transformadores (Transformers)

Arquitetura moderna usada nos LLMs.

### Funções:

- compreender contexto
- relacionar palavras distantes
- gerar texto coerente

Transformers substituíram muitas redes neurais antigas porque possuem:

- maior precisão
- paralelização
- melhor entendimento contextual

---

# Tokens

Tokens são pequenas partes de texto usadas pelos modelos.

### Exemplos:

Texto:

> “Olá mundo”

Pode virar:

- “Olá”
- “mundo”

Os modelos:

- recebem tokens como entrada
- geram tokens como saída

### Importância:

- custo da IA normalmente é baseado em tokens
- contexto máximo também depende dos tokens

# Agentes de IA

Um agente de IA usa:

- LLMs
- memória
- ferramentas externas
- automação

Para executar tarefas de forma autônoma.

### Exemplo:

Um agente pode:

1. pesquisar na internet
2. gerar código

4. corrigir erros
5. criar documentação

Tudo automaticamente.

- analisar aplicações

### Exemplo de fluxo:

1. Criar instrução:

> “Aja como especialista em Python”

3. Solicitar:

> “Analise e sugira melhorias”

# Engenharia de Prompt

Prompt engineering é a prática de criar instruções melhores para IA.

### Prompt ruim:

> “Crie um sistema”

### Prompt melhor:

> “Crie uma API REST em Spring Boot usando JWT, JPA e MySQL”

Quanto mais contexto:

- melhor resultado
- menos erros
